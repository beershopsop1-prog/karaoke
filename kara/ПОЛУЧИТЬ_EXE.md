# Как получить готовый .exe без установки программ

Я не могу прислать сам .exe: Windows-программа собирается только на Windows,
а я работаю на Linux. Но её соберёт за тебя GitHub — бесплатно, в облаке.
От тебя: один раз загрузить файлы, дальше просто скачивать готовое.

## Что изменилось в этом обновлении
- Приложение теперь ОДНА программа. Поиск текста встроен внутрь —
  Python-сервер для этого больше НЕ нужен.
- "Убрать вокал" стало необязательным (работает, только если позже
  настроишь доп. модуль). Без него приложение полностью рабочее:
  свои файлы + автопоиск текста + библиотека + очередь.
- Видеофон временно убран (мешал сборке под Windows), фон — красивый
  переливающийся градиент. Видео вернём, когда отладим ТВ.

## Шаги (10 минут, всё в браузере)

1. Заведи аккаунт на https://github.com (бесплатно), если нет.
2. Нажми "+" вверху справа -> "New repository". Имя любое, например
   `karaoke`. Нажми "Create repository".
3. На странице репозитория: "uploading an existing file".
4. Перетащи туда ВСЮ папку проекта `karaoke_app` (вместе с папкой
   `.github` внутри неё — важно, в ней лежит сборщик).
   Нажми "Commit changes".
5. Открой вкладку "Actions" вверху. Увидишь запущенную сборку
   "Собрать Windows exe". Подожди ~5 минут, пока не станет зелёной.
6. Зайди в этот завершённый запуск -> внизу блок "Artifacts" ->
   скачай `karaoke-windows`.
7. Распакуй скачанный архив, внутри запусти `karaoke_app.exe`. Готово.

Дальше при любой правке просто обновляешь файлы в репозитории —
новый .exe соберётся сам.

## Куда класть файлы из этого обновления
Замени ими одноимённые файлы в своём проекте `karaoke_app`:
- pubspec.yaml
- lib/services/lyrics_service.dart   (новый)
- lib/services/app_state.dart
- lib/screens/player_screen.dart
- lib/screens/add_song_screen.dart
- lib/screens/home_screen.dart
- .github/workflows/build-windows.yml  (новый)

Папку karaoke_backend можно пока не трогать — для одной программы она
не нужна, пригодится позже для удаления вокала.

Если на шаге 5 сборка покраснеет — пришли мне текст ошибки из лога,
поправлю.
